Proyecto TelecomX - Parte 1

Este proyecto, "TelecomX Parte 1", se centra en el análisis exploratorio de datos de clientes de telecomunicaciones . El objetivo principal de este notebook es la limpieza, el preprocesamiento y la comprensión inicial del conjunto de datos antes de pasar a un modelado más avanzado.
Contenido

El repositorio contiene un notebook de Jupyter que te guía a través del siguiente proceso:

    Carga de datos: Se carga el conjunto de datos inicial de clientes.

    Limpieza de datos: Se identifican y manejan valores faltantes, duplicados y errores en los datos.

    Análisis Exploratorio de Datos (EDA): Se realizan visualizaciones (gráficos) y análisis estadísticos para entender las características de los clientes, como la distribución de los servicios contratados, el tiempo de permanencia y los costos.

    Preparación para el modelado: Se preparan los datos para la siguiente etapa, que podría incluir la creación de nuevas variables o la codificación de variables categóricas.

Requisitos

Para ejecutar este notebook, necesitarás tener instaladas las siguientes bibliotecas de Python:

    pandas

    numpy

    matplotlib

    seaborn

    jupyter

Puedes instalarlas usando pip:
pip install pandas numpy matplotlib seaborn jupyter
Uso

Para ejecutar el análisis, sigue estos pasos:

    Abre el notebook TelecomX_LATAM.ipynb en tu entorno de Jupyter.

    Ejecuta cada celda en orden para seguir el flujo del análisis, desde la carga de datos hasta la preparación para el modelado.
